# Genetic Algorithm Optimization

This project implements a genetic algorithm to solve an optimization problem using evolutionary principles such as selection, crossover, and mutation.

## Context
University project focused on artificial intelligence and optimization techniques.

## Algorithm Overview
The genetic algorithm works as follows:
1. Initialize a population of candidate solutions
2. Evaluate the fitness of each individual
3. Select the fittest individuals for reproduction
4. Apply crossover to produce offspring
5. Apply mutation to maintain genetic diversity
6. Repeat until a termination condition is met

- Python 3

## Key Concepts
- Evolutionary algorithms
- Fitness functions
- Selection strategies
- Mutation and crossover operators
